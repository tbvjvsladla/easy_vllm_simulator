## 핵심 사건 — OOM-위장 실패 (코드 무결, 환경 오염)
- 1차 `--build`: **양노드 소스빌드 성공**(ABI 벽 통과), 그러나 서빙에서 master EXITED.
- `--keep-up` 재기동으로 전체 로그 확보 → 근본원인:
  `ValueError: Free memory cuda:0 73.5/121.69 GiB < 요청 91.27 GiB(util 0.75)`.
  → master 에 **단일노드 Phase 2 잔여 컨테이너 `vllm-srcbuild`** 가 live serve 로 ~36 GiB 점유(통합메모리 공유).
- NCCL/RDMA·Ray 2노드·TP=2 토폴로지·triton(MARLIN 폴백) 전부 정상 = 멀티노드 코드/설정 무결.
- 조치: `docker rm -f vllm-srcbuild` → GPU 해제 → **재빌드 없이 재실행 → READY ~320s → content='4' fr=stop → exit 0.** ✅
- 재실행은 기본(자동 down)이라 양노드 컨테이너 자동 정리 확인.
