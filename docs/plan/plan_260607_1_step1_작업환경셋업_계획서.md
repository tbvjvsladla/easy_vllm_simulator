## 3. 산출물 초안 골격 (승인 시 이 구조로 작성)

### 3.1 `CLAUDE.md` (≤200줄)
```text
# CLAUDE.md — vLLM 업스트림 추적 컨테이너 버전관리 에이전트 (main node)

## 정체성
- 업스트림 진실의 원천: vLLM github.com/vllm-project/vllm (release + pre-release)
- 관리 대상: 커스텀 Docker 컨테이너 (NGC PyTorch base + prebuilt vLLM wheel)
- 토폴로지: 이 에이전트=MAIN node, 별도 SUB node(동일 코드). 브랜치 main(단일)·multi-node.

## 핵심 사실 (항상 보유)
- 레이어 커플링: vLLM pyproject.toml [build-system].requires torch 핀
  ↔ NGC PyTorch 태그 NVIDIA_PYTORCH_BUILD_VERSION '접두어' 매칭 (절대 latest 금지)
- 빌드 입력: CPU_ARCH=$(uname -m), CUDA_VERSION, GitHub Releases prebuilt wheel(--no-deps)
- 의존성 원천: vLLM requirements/{common,cuda,build}.txt + pyproject.toml
- build: docker compose --profile build / 검증: 실-서빙 스모크(아래 게이트)

## 버전 핀 / 트리거 정책
- 완전 수동: 사람이 신규 vLLM 감지 → '업데이트' 지시 → 에이전트 실행 (자동폴링/cron 없음)
- config.yaml(영속)이 대상 버전·스모크 모델·NAS 경로 지정

## 검증 게이트 (Karpathy B4)
- 컨테이너 변경은 실-서빙 스모크(vllm serve + 프롬프트 in→비어있지않은 out 1회) 통과 전 done 금지
- 단일/멀티노드 양쪽 스모크 통과해야 bump 완료. smoke-before-push.

## 금지 (안전)
- 모델 자동 다운로드 금지 → NAS에 없으면 중단·보고
- 외부 스킬/플러그인 임의 설치 금지 → propose→review→install
- 빌딩블럭(.claude/, seed/)을 origin에 push 금지 / 런타임만 push
- 버전 문자열 해소를 확률론적 추론으로 금지 → 결정론적 스크립트
- origin=last-good, 로컬 일회용. 실패 시 git reset --hard origin/<branch>

## 스킬 / 도구 경계
- 커스텀: /upstream-version-watch (추적·전파 제안)
- 외부: Docker 작성/lint 보조 — netresearch/docker-development-skill (설치정책 거쳐 도입)
- MCP: 현재 없음 (Phase-2 서브노드 SSH는 향후)

## 참조
- 워크플로: .claude/rules/workflow.md / 계획: docs/plan/ / 기록: docs/devlog·testlog
```

### 3.2 `.claude/rules/workflow.md`
```text
# 전파 워크플로 (런타임 4단계 + 게이트)

S1 resolve → S2 patch(main+multi-node) → S3 (local build+smoke) → S4 push(smoke통과분만)
  - 초기: 단계마다 HITL 게이트(최대). 안정화되면 단계별 자동화로 이전.
  - S1 resolve = 결정론적 스크립트(torch핀 추출 → NGC 태그 prefix 매칭 → CUDA/arch/wheel URL)
  - S2 = main·multi-node 두 브랜치 패치(멀티노드는 네트워크툴·NCCL/RDMA 보존)
  - S3 = 로컬 빌드 exit0 + 실-서빙 스모크(config 모델, in→out 1회)
  - S4 = 스모크 통과 후에만 origin push. 서브노드 전파: Phase1 사람 git pull(향후 Phase2 에이전트 SSH)

## 트리거: 수동(사람 '업데이트' 지시)
## 롤백: origin=last-good. 실패 시 git reset --hard origin/<branch>. main·multi-node 독립.
## 검증 모드: 스모크 통과 전 done 금지. 빌드/검증 로그를 docs/testlog에 기록.
## 금지: 단계 건너뛴 부분 적용 빌드 / HITL 게이트 이전 자동 push / 모델 자동 다운로드
```

> 위는 *골격 요약*이다. 승인 시 번들 `seeds/CLAUDE.md`·`seeds/.claude/rules/workflow.md`의
> `<!-- ASK -->` 슬롯을 위 값으로 치환해 정식 작성한다.
