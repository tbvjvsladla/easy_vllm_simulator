## 2. 절단선 술어 (ㄱ) — 3원칙을 판정 가능한 문장으로

판정 순서는 R1 → R2 → R3 이며, R4 는 결과를 바꾸지 않고 **설계를 바꾼다**. 한 줄의 코드가 노드에 따라 등급이
다르면(`recipe.py:131` — 메인에서는 상위 게이트가 먼저 죽고 서브에서는 폴백이 산다) **서브 실행 경로 기준**으로 판정한다.
