### 1.3 서브→메인 hint 산출물 — Phase 감독이 없다

| 항목 | 현 상태 |
|---|---|
| 런타임 Phase 의 통로 | 서브→메인 상향은 **문서기반 only**(`fetch_sub_docs.sh` · docs 만 mirror). `output/**` 은 회수 대상 밖 |
| hint 발행이 요구하는 것 | 인증서(측정 키로 되찾음) + 렌더된 Dockerfile/compose + 트리플렛(3) + 런타임 패치(+1) + 빌드 패치(+1) + 이미지 digest |
| 서브 산출물 중 도달하는 것 | docs(인증서 포함) — 나머지는 **도달 경로가 없다** |
| Phase 를 구분하는 주체 | **없다.** relay/agent_control 은 턴제 위임을 알 뿐 "지금이 런타임 Phase 인지 발행 Phase 인지"를 모른다 |

**모호성**: 사용자 결정은 "`terraforming_node` 의 노드 오케스트레이터 하위기능이 Phase 별로 감독한다 —
런타임 Phase 엔 output 데이터 통신 금지, 완수 후 발행 Phase 엔 서브→메인 송신 허용". 인터뷰가 정할 것:
① Phase 전이의 **결정론 신호**(무엇이 "완수"를 증명하나 — 인증서? 원장 상태? 서브 리포트?) ② 발행 Phase 에
넘어오는 것의 **정확한 목록**과 PII 강도(서브 산출물이 배포 태그에 들어간다) ③ 감독자가 A2A 제어명령인가
sync 의 새 모드인가 별도 스크립트인가.

### 1.4 Agent Card ↔ manifest — 두 문서의 역할과 서브 manifest 의 소유

| 항목 | 현 상태(실측) |
|---|---|
| 서브 `Agent_Card.json.node_identity` | `role·rank·sub_mode·host·interconnect·platform_preset·cpu_arch·gpu_model·nas_mount` — **HW 사실과 정체성** |
| 서브에 manifest | **없다**(서브 `comms.md:113` · `CLAUDE.md:62` 가 같은 문장으로 못박음 · `sync_to_sub` D10 이 배달 제외) |
| 렌더러가 요구하는 것 | `cpu_arch·interconnect.platform_preset·nas_model_path·tiktoken_host_path·quant_model_path·topology·gpus_per_node·model_source·terraforming.complete/branch_verified` |
| Agent Card 로 커버되는 것 | HW 3종(cpu_arch·platform_preset·gpu_model) 만. per-task 경로·gpus_per_node·topology·terraforming.* 은 **없다** |
| 서브의 자기 판단 | *"서브는 HW-scan 권위 데이터를 스스로 만들지 않는다"* — 옳다(manifest 는 HW 사실의 단일 권위 · terraforming 이 스캔) |

**사용자 결정**: Agent Card = **A2A 평면 규약**(메인이 서브 수행 가능 범위를 *실측*한 것). 서브도
**manifest.yaml 을 갖는다**(자율 빌드→서빙→벤치의 결과물). manifest 생성·갱신·재설치는 **`terraforming_node`
소유** — 설치 과정에서 서브 manifest 도 만들어 준다.
**인터뷰가 정할 것**: ① 서브 manifest 의 **저작 주체와 시점**(메인 terraforming 이 렌더해 배달? 서브 스캔 +
메인 검증?) ② "manifest 는 서브에 없다"를 적은 **모든 자리**의 개정 범위(서브 CLAUDE.md·comms.md·
sync_to_sub D10·render_dockerfile 주석·recipe 리더) ③ 두 노드 manifest 가 **같은 HW 사실을 두 자리에**
드는 것의 단일 권위(갈라지면 침묵 누락 — `assert_band2_top_gitignore_parity` 류 교차검증이 필요한가).

## 4. 뿌리 패턴 5종

1. **침묵 terminal** (F5·F8·F10) — terminal 이 맞는데 *말없이* terminal. 헌법 노드제어 ③(처방 실행자 선기재)의 위반 형태.
2. **만든 것 ≠ 도는 것** (F1·F7·F11) — 주석·docstring 이 배선을 약속하고 코드가 없다. "동일 계약" 선언이 가장 위험하다.
3. **도구·평면 경계를 넘어 상수를 나름** (F2·F4) — 뜻이 다른 필드에 같은 이름·같은 값.
