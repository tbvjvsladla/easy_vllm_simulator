# DeepSeek-V4-Flash-0731 × vLLM 0.29.0rc6 — 2노드 GB10 최대 TPS 레시피 (광의탐색 결과)

> 발행: 2026-09-09 · 분류: perf · 캠페인 `camp-26090819-ds4f0731-kv3ctx2-multi`
> 판정 정본: `docs/testlog/testlog_26090912_ds4f0731_029rc6_광의탐색_종합판정.md`

## TL;DR

vLLM **0.29.0rc6**(pre-release)이 DeepSeek-V4-Flash-0731을 2×GB10(Ray TP=2)에서 **변종/포크 없이 stock**으로 서빙한다.
광의탐색(레버 스윕)으로 찾은 최대 TPS 레시피는 **fp8 KV + dspark 스페큘러티브(nspec=7) + CUDA graph + moe humming** 조합으로,
기준선 대비 **+82%**(768K: 17.11→31.12 t/s · 1M: 16.67→30.54 t/s).

## 측정 스코어보드 (decode t/s @동시성1 · GuideLLM 0.7.3 · in 1024/out 256)

| 구성 | 768K context | 1M context |
|---|---|---|
| 기본(eager·spec off) | 17.11 | 16.67 |
| + CUDA graph | 26.14 (+52.8%) | — |
| + dspark spec (nspec7) | 29.72 (+73.7%) | — |
| **+ 둘 다 (승자)** | **31.12 (+81.9%)** | **30.54 (+83.2%)** |
| moe-backend=triton | 엔진 거부(SILU 미지원) | — |

spec 수용길이(엔진 실측): 2.25~2.53. 디코드 속도는 context 길이(768K↔1M)에 무관(DSA 희소 효과). TTFT ~620~700ms(in 1K).

## 레시피 (승자 구성)

- 이미지: `easy-vllm:0.29.0rc6-cu133-aarch64-source` (NGC 26.07 베이스 · torch 2.13 · source-build)
- serve: `tensor-parallel-size 2 · distributed-executor-backend ray · gpu-memory-utilization 0.85`
- KV: `kv-cache-dtype fp8` (fp8_ds_mla로 강제 해소) · `kv-cache-memory-bytes 10737418240`(10GiB 클램프)
- spec: `speculative-config {"method":"dspark","num_speculative_tokens":7}` (≥ 모델 dspark_block_size 5)
- 기타: `moe-backend humming` · enforce-eager 해제(cudagraph) · reasoning/tool parser `deepseek_v4`
- 동접 상한: 768K→2 · 1M→1 (binding = 호스트 기동 밸리+절대 플로어 · KV 용량 아님)

## 알아둘 것 (이 환경의 벽 지도)

- **KV 무양자화(auto)·터보퀀트는 구조적 불가** — sm_121a는 SM120 attention 경로가 강제되고 그 포맷(fp8_ds_mla)은 fp8 접두어 KV만 받는다(0.26.0 동일). 터보퀀트는 dense/GQA 모델용이다.
- 0.25.1 시대의 flashinfer `decode_dsv4` page_block64 벽은 0.29 stock에서 해소됨(포크 불요). 반대로 그 시대의 `MATMUL_DECODE` 레버는 0.29에 없다(상류 이주로 cudagraph가 그 자리에 섰다).
- 기동 구간이 위험 구간: 155GiB 가중치 로드의 페이지캐시 밸리(~8GiB)가 호스트 메모리 플로어를 칠 수 있다 — KV 클램프는 이 밸리까지 포함해 산출해야 한다.
- moe-backend=auto는 MARLIN-repack OOM 전력 — 명시(humming)할 것.

## 유효맥락 · 재현 주의

이 수치는 2×GB10(sm_121a · RoCE) × vLLM 0.29.0rc6 × 이 체크포인트 한정이다. 다른 버전·GPU에서는 carry-forward 없이 재측정할 것. 지도=힌트이지 정답이 아니다.
