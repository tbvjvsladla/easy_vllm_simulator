## 한 문장

**메인은 서브의 자율성을 독려하며 위임하고, 메인 자신도 독립 캠페인을 수행한다.** 두 노드는 같은
연산에 참여하지 않으므로 lockstep 이 없고, 그래서 병렬이 가능하다.

## 전략 다섯

1. **자율성 독려가 기본값이다.** 서브는 A2A 원격 에이전트이므로 자기 빌드킷을 자율 저작하고 자기
   판단으로 셀을 돈다. 메인이 하는 것은 **위임(Task 발급)과 관측**이지 산출물 주입이 아니다.
2. **메인도 독립 캠페인을 수행한다.** 서브에 위임한 동안 메인이 노는 것은 설계 실패다 —
   `assignments` 의 노드별 리스트는 **동시에 돈다**(공통층 `workflow.md` §배정 계층).
3. **셀은 2계층이다** — 메인 셀과 위임 셀. **착수 순서는 서브 지시서가 먼저다**(사용자 결정):
   캠페인 init 직후, 메인 첫 셀 착수 **전에** `assignments[sub]` 파생 선언으로 서브 build context 를
   연다. 서브가 빌드를 도는 동안 메인이 자기 첫 셀을 돌면 벽시계가 겹친다(2026-09-07 실측: 순차
   7h27m → 동시 2h30m). 술어 P4 가 그 시각 순서를 본다.
4. **버전 핀은 노드마다 독립이다.** 집단 연산 ABI 커플링이 없으므로 서브가 다른 vLLM·torch 를 들어도
   무방하고, 그것이 오히려 축을 하나 더 준다.
5. **그라운딩은 비대칭이다.** 도서관과 사서는 메인 단독이다 — 복제하지 않고 차등 접근으로 연다.
   서브의 결정은 참조 인용으로 성립하며, 인용 없는 결정은 거짓이 아니라 **누락**이다(공통층).

## 캠페인 배정 — 셀은 노드 단위다

- `assignments` 에 메인과 서브가 각자 리스트를 갖고, **서로 다른 노드의 리스트는 동시에 돈다**.
  전이 모드(AUTO/HITL/STAY)는 노드별로 독립이다.
- 메인이 서브 진행을 읽는 유일한 자리는 `docs/logs/<node>/campaign_brief.json` 이다 — ssh 직접
  관측은 채널이 없을 때 사람이 만드는 우회다(2026-09-07 실측 32회).
- 감독은 상주가 아니라 한 걸음이다(`relay.py --supervise-step`) — 절차 정본은 공통층이다.
- 벤치(GuideLLM)는 **양 노드가 각자** 띄운다. 예산 파생이 노드마다 독립이어야 한다.

## 서브에 여는 것 / 열지 않는 것

| | 싱글에서 |
|---|---|
| 빌드킷 배달 평면 | **dormant** — 서브가 자율 저작한다 |
| 에이전트 환경 오버레이 | **active** — 이것이 확장기능의 내용이다 |
| 서브 런타임 스킬 | **on**(tool_plane 3종) — 정본은 `node_role_contract` 파생값 |
| 서브의 자율 빌드 판단 | ✔ — 독려한다 |
| 서브 → 메인 상향 | 문서기반 회수만(공통층) |
