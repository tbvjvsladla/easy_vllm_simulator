# 싱글노드 인계 예외

**topology: single** · layer: topology · policy:BRANCH_CONSTITUTION_LAYERING

반환 결과에서 실제 누락·모순이 드러난 경우에만 읽는다. 정상 인계에 별도 감사를 추가하지 않는다.

- 메인은 해당 문제의 설명·정정을 서브에 요청한다. 서브가 자기 owner workflow에서 처리한 뒤 반환한 결과를 인수한다.
- 해결된 부분을 다시 열거나 서브 원시 자료·디스크를 조사하지 않는다. 인계 자체나 막연한 가능성은 재검증 근거가 아니다.
- 실제 희귀 예외에 전체 재검증이 필요하면 기존 업무 소유·승인 경계 안에서 처리한다. 메인의 서브 전체 감사 권한을 신설하지 않는다.
- 이미 유효하게 완료된 결과에 새 문제 없는 지시가 반복되면 기존 relay가 결과를 재사용한다. 새 worker 실행·사용자 승인·캠페인 중단을 추가하지 않는다. 기존 필수·안전 게이트는 유지한다.
