# 멀티노드 인계 예외

**topology: multi** · layer: topology · policy:BRANCH_CONSTITUTION_LAYERING

반환 결과에서 실제 분산 연결 문제가 드러난 경우에만 읽는다. 정상 인계에 별도 감사를 추가하지 않는다.

- 메인은 해당 문제의 설명·정정을 요청하고 기존 분산 workflow에서 정합을 회복한다.
- 설명·정정으로도 해결되지 않은 연결 쟁점만 서브가 제출한 추가 근거로 확인한다. 무관한 노드·기능의 전수 감사로 넓히지 않는다.
- 이미 유효한 결과는 재사용한다. 실제 희귀 예외의 전체 재검증은 기존 업무 소유·승인 경계 안에서 해당 과업의 필요 범위에 한정한다.
- 같은 완료 결과에 새 문제 없는 지시가 반복되면 기존 relay가 결과를 재사용한다. 새 worker 실행·사용자 승인·캠페인 중단을 추가하지 않는다. 기존 필수·안전 게이트는 유지한다.
